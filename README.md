# SPA_PLANTILLA

Proyecto práctico desarrollado para aprender cómo funciona una **SPA (Single Page Application)** utilizando:

* HTML
* CSS
* JavaScript Vanilla
* Axios
* JSON Server

La aplicación incluye:

* Login básico
* Navegación entre vistas sin recargar
* Consumo de API falsa
* Validaciones
* Renderizado dinámico de productos
* Formulario de contacto

---

# Tecnologías

* HTML5
* CSS3
* JavaScript
* Axios
* JSON Server

# Instalación

## Instalar JSON Server

```bash id="j03mgn"
npm install -g json-server
```

---

## Ejecutar la API

```bash id="fdzujm"
json-server --watch db.json
```

La API correrá en:

```bash id="zzg2gk"
http://localhost:3000
```
